# Bookmark Alive (북마크 얼라이브)

크리에이터·디자이너를 위한 북마크 심폐소생 서비스 — 쌓아둔 영감을 다시 살려드립니다.

## 프로젝트 정보
- **유형**: 크롬 익스텐션 기반 개인 도구 (크리에이터 특화 SaaS)
- **타겟 사용자**: 크리에이터, 디자이너
- **출시 목표**: 미정

## 핵심 기능
- 방치된 링크 심폐소생 (3개월 이상 미클릭 링크 재추천)
- AI 자동 분류 및 3줄 요약
- 스마트 정리 (깨진 링크·중복 링크 탐지)
- 리마인드 알림 "오늘의 영감" (매일 아침 3개 추천)
- 비주얼 카드 뷰 대시보드 (OG 이미지 기반)

## 폴더 구조 (5개 팀)
- `planning/` — 기획 팀: 무엇을 만들 것인가
- `design/` — 디자인 팀: 어떻게 보여줄 것인가
- `cx/` — CX 팀: 누가 어떻게 사용할 것인가
- `marketing/` — 마케팅 팀: 어떻게 알릴 것인가
- `strategy/` — 전략 팀: 어떻게 지속 가능하게 만들 것인가
