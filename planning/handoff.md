## 2. 제품 톤 & 보이스

### 2.1 한 줄 포지셔닝
> "저장만 하고 잊은 링크, 다시 살아납니다."

### 2.2 보이스 키워드
| 방향 | 설명 | 예시 |
|------|------|------|
| **따뜻하고 친근함** | 딱딱한 기술 언어 지양 | "분석 완료" ❌ → "AI가 정리했어요 ✅" |
| **간결함** | 2줄 이상 설명 피함 | 버튼 레이블: "저장하기", "열어보기", "정리하기" |
| **공감 기반** | 사용자의 상황을 먼저 말함 | "저장만 해두셨죠? 이제 꺼내 쓸 시간이에요" |
| **적당한 유머** | 딱딱한 오류 메시지 지양 | "연결이 끊겼어요. 잠깐만요 🌐" |

### 2.3 금지 표현
- "오류가 발생했습니다" → "잠깐, 뭔가 문제가 생겼어요"
- "로딩 중" → "분석하고 있어요" / "불러오는 중"
- "삭제하시겠습니까?" → "이 링크를 지울까요? 되돌릴 수 없어요."
- 영어 전문 용어 그대로 노출 (예: "404 Error") → "이 페이지는 사라진 것 같아요"

### 2.4 핵심 UI 카피 샘플

| 상황 | 카피 |
|------|------|
| 온보딩 웰컴 타이틀 | "잊혀진 링크를 다시 꺼내 쓸 시간이에요" |
| 임포트 완료 | "N개 북마크를 가져왔어요! AI가 정리를 시작할게요 ✨" |
| 첫 추천 카드 | "저장해두셨던 이 링크, 지금 딱 좋을 것 같아요" |
| 데드링크 발견 | "이 링크는 이제 사라진 것 같아요. 지울까요?" |
| 검색 결과 없음 | "'키워드'와 맞는 링크를 못 찾았어요. 다른 단어로 시도해보세요" |
| 빈 대시보드 | "아직 영감이 쌓이는 중이에요. 링크를 더 저장해보세요 📌" |
