# MVP 범위 & 우선순위 (MVP Scope)

> Bookmark Alive가 **출시 시점에 무엇을 갖추고, 무엇을 포기할지**의 기준.
> 판단 기준: "북마크 500개 이상 가진 디자이너가 설치 후 5분 내 첫 가치를 체험"할 수 있는 최소 조합.

---

## 1. 우선순위 매트릭스 (Impact × Effort)

**가로축**: Impact — 타겟 사용자에게 주는 가치
**세로축**: Effort — 개발 난이도

```
          낮은 Impact              높은 Impact
          ┌─────────────────────┬─────────────────────┐
  낮은     │ 🟨 나중에도 OK       │ 🟢 MVP 즉시 포함     │
  Effort  │                     │                     │
          │ - 다크모드           │ - Chrome HTML 임포트 │
          │ - 검색 단축키         │ - 카테고리 자동 분류  │
          │                     │ - 3줄 요약            │
          │                     │ - 카드 뷰 대시보드    │
          │                     │ - 데드링크 탐지       │
          │                     │ - 전체 텍스트 검색    │
          ├─────────────────────┼─────────────────────┤
  높은     │ 🟥 드롭              │ 🟦 MVP 이후 순차 추가 │
  Effort  │                     │                     │
          │ - Safari API 직접 연동│ - 시즈널·컨텍스트 매칭│
          │ - 팀 협업 기능        │ - 리마인드 알림       │
          │                     │ - 해시태그 자동 생성  │
          │                     │ - 벌크 에디트         │
          │                     │ - 중복 제거           │
          └─────────────────────┴─────────────────────┘
```

---

## 2. MVP 포함 기능 (Must Have)

**기준**: 위 매트릭스의 🟢 영역 + 🟦 중 온보딩·리텐션에 핵심인 것.

| 기능 | 설명 | 이유 |
|------|------|------|
| Chrome HTML 임포트 | 기존 북마크 일괄 가져오기 | 온보딩의 **첫 관문**. 이게 없으면 "새로 저장하기" 지옥 |
| 폴더 구조 유지 | 기존 계층 그대로 재현 | 사용자가 기존 노력 잃지 않는다는 **신뢰 확보** |
| AI 카테고리 자동 분류 | 7개 기본 카테고리 자동 지정 | "정리 안 됨" 고민 **즉시 해결** |
| 3줄 요약 | LLM 본문 요약 | 카드 뷰에서 **클릭 전 내용 파악** 가능 |
| 카드 뷰 대시보드 (OG 이미지) | 비주얼 그리드 | 디자이너 타겟에게 **필수 UX** |
| 데드링크(404) 탐지 | 주 1회 스캔 | 위생 관리의 **최소 기능** |
| 전체 텍스트 검색 | 제목+태그+요약 통합 검색 | "있는 줄 아는데 못 찾는" **핵심 pain 해결** |
| 방치 링크 심폐소생 (기본) | 3개월+ 미클릭 링크 표시 | 제품의 **정체성 기능** |
| 리마인드 "오늘의 영감" (이메일) | 매일 3개 추천 | 리텐션 핵심, 푸시는 이후 |

### MVP 범위 한 줄 요약
> **크롬 익스텐션으로 북마크를 가져와서, AI가 분류·요약해주고, 카드 뷰에서 찾고, 방치된 링크를 매일 3개씩 이메일로 되살려준다.**

---

## 3. MVP 이후 (Should Have → Nice to Have)

### Phase 2 (출시 +1~2개월)
- **시즈널 & 컨텍스트 매칭**: 시즌·관심사·랜덤 3로직 완성 — 제품 차별점 완성
- **해시태그 자동 생성**: 카테고리 위에 세부 태그 레이어 추가
- **푸시 알림**: 이메일에서 모바일 푸시로 확장
- **벌크 에디트**: 대량 정리 사용자 대응
- **중복 제거**: 데이터 위생 2단계

### Phase 3 (출시 +3~6개월)
- **Whale·Safari 임포트 확장**
- **실행 메모**
- **커스텀 카테고리**
- **검색 단축키·고급 필터**
- **다크모드**

### Phase 4 (장기)
- 팀·에이전시 협업 기능
- API 공개 (다른 도구와 연동)
- 모바일 전용 앱

---

## 4. 의도적으로 드롭하는 것 (Won't Have)

| 항목 | 드롭 이유 |
|------|---------|
| Safari API 직접 연동 | Apple 제약 많음 + HTML 임포트로 우회 가능 |
| 클라우드 동기화 (자체 서버) | 초기엔 크롬 Storage API로 충분 |
| 북마크 공유·SNS 연동 | 개인 도구 포지셔닝과 상충 |
| 유료 플랜 기능 (Phase 2까지는) | 먼저 무료 사용자 가치 검증 후 전환 |

---

## 5. MVP 성공 판정 기준

**정량 지표** (출시 +3개월 시점)
- MAU 500명 이상 (PRD §7 목표 일치)
- 설치 ~ 첫 카드 클릭 중간값 **5분 이내**
- 주간 재방문율 **30% 이상**
- "오늘의 영감" 이메일 오픈율 **40% 이상**

**정성 지표**
- 디스콰이엇·프로덕트 헌트 피드백에서 **"AI 분류가 정확하다"** 언급 상위 3위 안
- 부정 피드백 중 "임포트 실패" 비율 **10% 미만**
