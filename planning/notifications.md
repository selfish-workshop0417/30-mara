# 알림 콘텐츠 스펙 (Notifications)

> "오늘의 영감" 이메일 및 푸시 알림의 **콘텐츠 구조·샘플·발송 규칙** 정의.
> 디자인팀(이메일 템플릿)과 개발팀(발송 로직)이 함께 참조.

---

## 1. 이메일 — "오늘의 영감" (MVP 필수)

### 1.1 발송 규칙
| 항목 | 기준 |
|------|------|
| 발송 주기 | 매일 (기본) — 설정에서 주 3회·주 1회로 변경 가능 |
| 발송 시각 | 오전 8시 (사용자 로컬 타임존) |
| 발송 조건 | **가입 단계별로 다름** (아래 §1.1-A 참조) |
| 재발송 방지 | 동일 링크는 **14일 이내 재노출 금지** |
| 구독 해지 | 이메일 하단 "수신 거부" 링크 → 1클릭 해지 (법적 필수) |

#### 1.1-A. 단계별 이메일 전략 (첫 1주일 리텐션 갭 해결)

> 신규 가입자는 방치 기준(90일)을 충족한 링크가 없어 기본 로직으로는 이메일이 발송되지 않음.
> 아래 3단계 전략으로 이탈 방지.

| 기간 | 이메일 타입 | 발송 조건 |
|------|-----------|---------|
| 가입 당일 | **웰컴 이메일** | 온보딩 완료 직후 1회 |
| 가입 후 1~7일 | **"새로 저장한 영감" 요약** | 북마크가 1개 이상 있으면 발송 (최근 저장 중 추천) |
| 가입 후 8일~ | **오늘의 영감 (심폐소생)** | 방치 링크 3개 이상 시 정규 발송으로 전환 |

**웰컴 이메일 (가입 당일) 샘플**
```
제목: 북마크 N개를 AI가 정리했어요 ✅
본문: "방금 정리된 당신의 북마크를 둘러보세요.
      AI가 카테고리를 나눴어요. 맞게 분류됐는지 확인해보세요."
CTA: [내 북마크 보러 가기]
```

### 1.3 실제 샘플 콘텐츠

**제목 (Subject line) 패턴**
- 시즌 매칭: `[오늘의 영감] 작년 이맘때 저장해뒀던 링크, 기억하세요?`
- 관심사 매칭: `[오늘의 영감] "미니멀 UI" 찾고 계셨죠? 이 링크 어때요`
- 기본: `[오늘의 영감] 오늘 다시 볼 링크 3개 도착 📌`

**카드 매칭 레이블 (이메일에 표시)**
| 추천 로직 | 사용자에게 보이는 레이블 |
|---------|------------------|
| 시즌 매칭 | "📅 작년 {월}에 저장한 링크" |
| 관심사 매칭 | "🔍 최근 관심사와 연결된 링크" |
| 랜덤 영감 | "✨ 예전에 중요 표시했던 링크" |

### 1.4 이메일 기술 스펙
| 항목 | 스펙 |
|------|------|
| 폭 | 600px 고정 |
| 폰트 | 시스템 폰트 폴백 (`-apple-system, 'Noto Sans KR', sans-serif`) |
| 다크모드 | `@media (prefers-color-scheme: dark)` 지원 |
| 이미지 | OG 이미지 미존재 시 도메인 파비콘 + 색상 배경 폴백 |
| CTA 버튼 | 텍스트 링크 폴백 병행 (이미지 미지원 클라이언트 대응) |
| 발송 도구 | MVP: SendGrid / 추후 사용자 맞춤화 시 자체 발송 검토 |

## 2. 푸시 알림 (Phase 2)

> MVP에서는 이메일만. 푸시는 Phase 2에서 추가. 아래는 사전 설계용.

### 2.1 타입별 푸시 샘플

**타입 A — 오늘의 영감**
```
제목: 오늘의 영감이 도착했어요 📌
본문: 작년 이맘때 저장해둔 "봄 컬러 트렌드" 외 2개
액션: [지금 보기]
```

**타입 B — 데드링크 감지**
```
제목: 북마크 정리가 필요해요 🧹
본문: 접속 불가 링크 3개를 발견했어요
액션: [정리하기]
```

**타입 C — AI 분류 완료**
```
제목: 북마크 분석이 끝났어요 ✅
본문: 840개 링크를 7개 카테고리로 정리했어요
액션: [대시보드 열기]
```

### 2.2 푸시 발송 규칙
| 항목 | 기준 |
|------|------|
| 하루 최대 발송 | 2건 (오버 알림 방지) |
| 야간 금지 시간 | 밤 10시 ~ 오전 7시 |
| 옵트인 방식 | 첫 설치 후 별도 권한 요청 팝업 |

## 3. 인앱 알림 (토스트·배너)

| 상황 | 위치 | 내용 | 지속시간 |
|------|------|------|---------|
| 임포트 완료 | 상단 배너 | "N개 북마크를 가져왔어요! AI 분류를 시작할게요" | 영구 (확인 클릭까지) |
| AI 분류 완료 | 상단 배너 | "N개 분류 완료! 오늘의 영감을 준비했어요" | 영구 |
| 링크 저장 완료 | 우하단 토스트 | "저장됐어요 ✓" | 2초 |
| 데드링크 발견 | 대시보드 배너 | "정리가 필요한 링크 N개 발견 →" | 영구 (해결 전까지) |
| 네트워크 오류 | 상단 토스트 | "연결이 끊겼어요. 다시 시도해주세요" | 5초 + 재시도 버튼 |
