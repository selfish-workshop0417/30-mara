# 비즈니스 규칙 & 트리거 로직 (Rules)

> **AI 동의 플로우 · 차별 기능 트리거 규칙 · 예외 처리**를 정의.
> 개발팀 구현 기준서로 활용.

---

## 1. 개인정보 & AI 처리 동의

### 1.1 동의 수집 시점
- **온보딩 A-2 화면** (임포트 선택 단계)에서 동의 받음
- 동의 체크박스 미선택 시 "가져오기 시작" 버튼 비활성화
- 나중에 가져오기 선택 시에도 AI 기능 진입 전 동의 필수

### 1.2 동의 내용 (사용자에게 보이는 텍스트)
```
북마크 분석을 위해 링크의 제목·URL·본문 일부를 AI 처리합니다.
개인 식별 정보는 전송되지 않습니다. 자세히 보기 [링크]
```

### 1.3 동의 거부 시 제공 기능
| 기능 | 동의 O | 동의 X |
|------|:------:|:------:|
| 북마크 임포트 | ✅ | ✅ |
| 폴더 구조 유지 | ✅ | ✅ |
| 수동 카테고리 지정 | ✅ | ✅ |
| AI 카테고리 자동 분류 | ✅ | ❌ |
| 3줄 요약 | ✅ | ❌ |
| 전체 텍스트 검색 | ✅ (요약 포함) | ✅ (제목·URL만) |
| 오늘의 영감 추천 | ✅ | ⚠️ 기본 랜덤만 |

### 1.4 동의 철회
- 설정 > 개인정보 > "AI 처리 동의 철회"
- 철회 시: 기존 요약·태그 데이터 삭제 여부 선택 팝업

## 2. 심폐소생 트리거 규칙

### 2.1 방치 링크 판정
| 조건 | 기준 |
|------|------|
| 방치 기간 | 마지막 클릭일로부터 **90일 이상** |
| 제외 기준 | 중요 표시(`⭐`)된 링크는 제외 (별도 랜덤 영감으로만 노출) |
| 데드링크 | 404 판정 링크는 심폐소생 대상에서 제외 |

### 2.2 하루 추천 3개 구성 비율
| 슬롯 | 로직 | 비중 |
|------|------|------|
| 슬롯 1 | 시즌 매칭 | 고정 |
| 슬롯 2 | 관심사 매칭 | 고정 |
| 슬롯 3 | 랜덤 영감 | 고정 |
> 해당 로직 대상 링크가 없으면 → 방치 링크 최신순으로 자동 대체

### 2.3 재노출 방지
- 한 번 추천된 링크는 **14일 이내 재추천 금지**
- 사용자가 "다시 보지 않기" 클릭 시 **90일 이내 재추천 금지**
- 사용자가 링크를 직접 클릭하면 방치 타이머 리셋 (90일 카운트 재시작)

## 3. 시즌 매칭 트리거 규칙

### 3.1 시즌 판정 기준
```
시즌 매칭 대상 = (저장일의 월 == 현재 월) AND (저장 연도 < 올해)
```
- 예: 오늘이 4월 17일 → 작년(또는 그 이전) 4월에 저장된 링크

### 3.2 업계 행사 시즌 (MVP 이후 추가)
- 디자인: Adobe MAX(10월), Cannes Lions(6월), 디자인 위크(4월·9월)
- 마케팅: 블랙프라이데이(11월), 발렌타인(2월)
- 구현 방식: 내부 캘린더 데이터 + 사용자 카테고리 교차 매칭

## 4. 관심사 매칭 트리거 규칙

### 4.1 관심사 소스 (MVP)
- **직접 입력**: 온보딩 A-2 단계에서 관심 키워드 최대 5개 입력
- 예: `미니멀 UI`, `타이포그래피`, `앱 디자인`, `퍼스널 브랜딩`

### 4.2 관심사 소스 (Phase 2 — 자동 감지)
- 최근 저장 링크의 태그 빈도 분석 → 상위 키워드 자동 추출
- 사용자 확인·수정 가능 (설정 > 관심사 관리)

### 4.3 매칭 로직
```
관심사 매칭 대상 = 북마크 키워드(태그 OR 요약) ∩ 관심사 키워드 중
                   마지막 클릭일로부터 90일 이상 된 것
```

## 5. 데이터 위생 비즈니스 규칙

### 5.1 데드링크 처리
| 상황 | 규칙 |
|------|------|
| 404 2회 연속 | "데드링크" 판정 → 삭제 권고 |
| 일시적 서버 오류(5xx) | 판정 제외, 다음 스캔에서 재확인 |
| 사용자가 "무시"한 링크 | 30일간 재경고 금지 |
| 이후 복구된 링크 | 자동으로 데드링크 판정 해제 |
| Wayback Machine 대체 | 사용자 선택 시만 적용 (자동 대체 없음) |

### 5.2 중복 제거 처리 (Phase 2)
| 상황 | 규칙 |
|------|------|
| 완전 동일 URL | 중복으로 판정, 대표 위치 선택 제안 |
| URL 파라미터만 다른 경우 | "관련 링크" 제안 (강제 병합 없음) |
| 제목은 같지만 URL 다른 경우 | 중복 제외 (콘텐츠 업데이트로 판단) |
| 병합 후 실행 취소 | 30일 이내 복구 가능 (소프트 딜리트) |

### 5.3 스캔 주기 및 비용 최적화
| 항목 | 기준 |
|------|------|
| 기본 스캔 주기 | 주 1회 (일요일 오전 3시) |
| 배치 처리 | 링크 수에 관계없이 동시 최대 20개 요청 |
| 타임아웃 | 요청당 5초, 초과 시 "확인 불가" 처리 |
