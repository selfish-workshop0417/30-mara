# 사용자 시나리오 (Scenarios)

> Bookmark Alive를 **누가·언제·어디서·왜·어떻게** 쓰는가.
> PRD §5(CX) 페르소나 "북마크 500개 이상, 활용률 5% 미만 디자이너/크리에이터"를 기준으로 3가지 대표 시나리오 전개.

---

## 페르소나 요약

**이름**: 이서영 (가칭)
**역할**: 프리랜서 디자이너 (6년차)
**북마크 현황**: Chrome 북마크 약 840개, 5단계 폴더 구조, 최근 3개월 클릭률 3%
**고민**: "저장은 열심히 했는데, 막상 필요할 때 뭘 저장했는지 기억이 안 나요"

---

## 시나리오 1 — 첫 사용 (온보딩)

### Who
이서영 (디자이너, Bookmark Alive 첫 사용자)

### When
월요일 오전 10시, 새 프로젝트 킥오프 직후

### Where
자택 작업실, 크롬 브라우저

### Why
상세페이지 디자인 레퍼런스가 필요한데, 북마크 폴더에서 뭘 저장해뒀는지 기억이 안 남.
"정리 안 된 북마크" 문제를 해결해보자고 마음먹음.

### How
1. 디스콰이엇에서 Bookmark Alive 소개글을 보고 크롬 스토어에서 설치
2. 설치 직후 "기존 북마크 가져올까요?" 안내 → **승인**
3. 약 840개 북마크가 45초 만에 임포트, 폴더 구조 그대로 재현됨
4. AI가 카테고리·태그·3줄 요약 자동 생성 (백그라운드, 약 3분)
5. 완료 알림 후 대시보드 진입 → **"오늘의 영감" 3개** 표시
6. 첫 카드 클릭 → 잊고 있던 "인스타 상세페이지 모음" 발견 → 프로젝트에 바로 활용

### 성공 지표
- 설치 ~ 첫 카드 클릭까지 **5분 이내**
- 첫 세션에서 **링크 1개 이상 클릭**

---

## 시나리오 2 — 일상 재방문

### Who
이서영 (Bookmark Alive 사용 2주차)

### When
화요일 아침 9시, 커피 마시며 메일 체크 시간

### Where
데스크톱 + 모바일 (알림은 폰으로, 클릭은 데스크톱으로)

### Why
매일 아침 "오늘의 영감" 알림이 루틴이 됨. 출근 전 5분 영감 충전용.

### How
1. 오전 8시: 이메일로 "오늘의 영감 3개" 푸시 도착
   - 1번: 작년 4월 저장한 "봄 시즌 컬러 트렌드" (시즌 매칭)
   - 2번: 최근 검색어 "미니멀 UI"와 연결된 3개월 전 저장 링크 (관심사 매칭)
   - 3번: 중요 표시해둔 "디자인 불변의 법칙" 아티클 (랜덤 영감)
2. 모바일에서 제목만 훑어보고 "2번이 흥미롭다" 생각
3. 오전 9시 데스크톱 로그인 → 2번 카드 클릭 → 3줄 요약 확인 → 링크 방문
4. 읽고 나서 실행 메모에 "이번 주 X 프로젝트 로고에 적용" 남김

### 성공 지표
- 주간 알림 **오픈율 40% 이상**
- 클릭한 링크 **30% 이상에서 실행 메모 남김**

## 시나리오 3 — 과거 자료 검색 & 정리

### Who
이서영 (사용 2개월차, 신규 저장 300개 + 기존 840개 = 약 1140개 보유)

### When
금요일 오후 3시, 새 클라이언트 미팅 전 자료 준비

### Where
데스크톱 크롬, 2개 모니터 (미팅 자료 + Bookmark Alive 동시 띄움)

### Why
클라이언트가 "F&B 브랜드 리뉴얼" 레퍼런스를 요청. 예전에 관련 자료를 저장했던 기억이 있음.

### How
1. `Cmd+K` 단축키로 검색창 호출
2. "F&B 브랜드" 입력 → 실시간 검색 결과 12개 표시
   - AI 요약 본문까지 검색하니 제목에 없던 관련 링크도 발견됨
3. 필터로 "저장일 1년 이내" 적용 → 6개로 축약
4. 체크박스로 6개 선택 → **벌크 에디트**로 태그 `#2026_F&B_리뉴얼` 일괄 부여
5. 대시보드 "정리가 필요한 링크" 배너 확인 → 데드링크 2개 발견, 일괄 삭제
6. 미팅용 레퍼런스 정리 완료 — 총 소요 시간 8분

### 성공 지표
- 검색 → 원하는 링크 발견까지 **30초 이내**
- 벌크 에디트 완료까지 **3분 이내**

## 시나리오에서 도출되는 핵심 요구사항

| 시나리오 | 강조되는 기능 | 구현 우선순위 |
|---------|-------------|-----------|
| 1 (온보딩) | 스마트 임포트, AI 자동 분류, 카드 뷰 | **Must** |

| 3 (검색·정리) | 전체 텍스트 검색, 벌크 에디트, 데이터 위생 | **Must** (벌크 에디트는 MVP 이후) |
