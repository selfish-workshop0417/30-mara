## 1. 네비게이션 트리 (전체 IA)

```
Bookmark Alive
│
├── [A] 온보딩 플로우 (첫 설치 ~ 첫 대시보드 진입)
│   ├── A-1. 설치 완료 웰컴
│   ├── A-2. 북마크 임포트 선택
│   ├── A-3. 임포트 진행 중
│   ├── A-4. AI 분류 진행 중
│   ├── A-5. AI 분류 미리보기 (확인·수정)  ← 추가
│   └── A-6. 온보딩 완료 + 첫 대시보드 진입
│
├── [B] 대시보드 (메인 허브)
│   ├── B-1. 오늘의 영감 섹션 (재추천 카드 3개)
│   ├── B-2. 새로 추가된 영감 섹션
│   └── B-3. 정리가 필요한 링크 섹션
│
├── [C] 검색
│   ├── C-1. 검색창 (빈 상태)
│   ├── C-2. 검색 결과 목록
│   └── C-3. 검색 결과 없음
│
├── [D] 카드 상세
│   ├── D-1. 카드 상세 뷰
│   └── D-2. 실행 메모 편집 (추후)
│
├── [E] 정리 센터 (Data Hygiene)
│   ├── E-1. 데드링크 목록
│   └── E-2. 중복 링크 목록 (추후)
│
├── [F] 설정
│   ├── F-1. 알림 설정 (이메일 / 주기)
│   ├── F-2. 카테고리 관리
│   └── F-3. 개인정보 & AI 처리 동의
│
└── [P] 익스텐션 팝업 (360px 미니 뷰)  ← 추가
    └── P-1. 빠른 링크 저장
```

**총 화면 수**: MVP 기준 **16개** (A-1~5, A-6, B-1~3, C-1~3, D-1, E-1, F-1~3 + 팝업 P-1)

## 2. 글로벌 레이아웃 & 네비게이션

대시보드 진입 이후 **모든 화면(B~F)**에 공통 적용되는 레이아웃.

```
┌──────────────────────────────────────────────────────┐
│  [로고]   대시보드   검색   정리센터   [+ 링크 추가]  [설정] │  ← 탑바
├──────────────────────────────────────────────────────┤
│                                                      │
│                   [메인 콘텐츠 영역]                  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| 로고 | 클릭 시 대시보드(B-1)로 이동 |
| 대시보드 | B-1 (메인 허브) |
| 검색 | C-1 (검색창) / `Cmd+K` 단축키와 동일 |
| 정리센터 | E-1 (데드링크·위생 관리) + 정리 필요 개수 배지 |
| **+ 링크 추가** | 강조 버튼 — 현재 탭 URL로 빠른 저장 (→ 인라인 모달) |
| 설정 | F-1 (드롭다운 메뉴: 알림·카테고리·개인정보) |

### "새 링크 추가" 방법 3가지 (P-1 팝업 포함)

| 방법 | 진입 경로 | 설명 |
|------|---------|------|
| **탑바 "+ 링크 추가" 버튼** | 대시보드 탑바 | 현재 탭 URL 자동 입력, 카테고리 선택 후 저장 |
| **익스텐션 팝업 (P-1)** | 브라우저 우상단 익스텐션 아이콘 클릭 | 어느 페이지에서든 북마크 저장 (핵심 일상 플로우) |
| **우클릭 컨텍스트 메뉴** | 링크 우클릭 | "Bookmark Alive에 저장" 메뉴 항목 |

### P-1. 익스텐션 팝업 (360px)

```
┌──────────────────────────┐
│  BOOKMARK ALIVE          │
├──────────────────────────┤
│  현재 페이지             │
│  [제목 자동 입력 인풋]   │
│  [URL 자동 입력]         │
│  카테고리: [드롭다운 ▼]  │
│  [저장하기]  [나중에]    │
├──────────────────────────┤
│  오늘의 영감 미리보기    │
│  ▸ [추천 링크 제목 1]    │
│  ▸ [추천 링크 제목 2]    │
│  [대시보드 열기 →]       │
└──────────────────────────┘
```

## 3. 온보딩 플로우 단계별 (A 영역)

### A-1. 설치 완료 웰컴
- **진입**: 크롬 익스텐션 설치 직후 자동 열림
- **내용**: 서비스 한 줄 소개 + 주요 기능 3가지 (임포트·분류·심폐소생)
- **버튼**: "지금 시작하기" (→ A-2)
- **건너뛰기**: 없음 (필수 플로우)

### A-2. 북마크 임포트 선택
- **내용**: 가져오기 방법 선택
  - 옵션1: Chrome 북마크 자동 연결 (Chrome API, 권장)
  - 옵션2: HTML 파일 직접 업로드
- **개인정보 동의**: ⚠️ **여기서 AI 처리 동의 받음** (rules.md §1 참조)
  - 동의 체크박스 필수 후 "가져오기 시작" 버튼 활성화
- **버튼**: "가져오기 시작" (→ A-3) / "나중에 하기" (→ B-1 빈 상태)

### A-3. 임포트 진행 중
- **내용**: 실시간 프로그레스 바 + "N개 발견 중..."
- **완료 후**: 자동으로 A-4로 전환
- **취소 버튼**: 있음 (→ 취소 확인 팝업)
- **에러 시**: A-3-ERR 화면 (§3 에러 상태 참조)

### A-4. AI 분류 진행 중
- **내용**: "AI가 북마크를 분석하고 있어요" + 예상 완료 시간
- **백그라운드 처리**: 닫아도 계속 진행, 완료 시 알림
- **버튼**: "백그라운드에서 계속" (→ B-1 스켈레톤 상태)

### A-5. AI 분류 미리보기 (확인·수정)
- **내용**: AI가 분류한 결과 요약 ("디자인 234개, 마케팅 89개, 미분류 32개")
- **미분류 항목**: 상단에 강조 표시 + "직접 지정하기" CTA
- **잘못 분류된 항목 수정**: 카드 탭으로 카테고리 선택 가능
- **버튼**: "확인, 계속하기" (→ A-6) / "나중에 정리할게요" (→ A-6 건너뜀)

### A-6. 온보딩 완료
- **내용**: "총 N개 정리 완료" + 첫 추천 카드 3개 미리보기
- **버튼**: "대시보드 보기" (→ B-1)

---

## 4. 대시보드 (B 영역)

### B-1. 오늘의 영감 섹션
- 재추천 카드 3개 (OG 이미지 + 제목 + 3줄 요약 + 저장일)
- 카드 클릭 → D-1
- "더 보기" → 추천 목록 전체

### B-2. 새로 추가된 영감 섹션
- 최근 7일 내 추가 링크 그리드 (카드 뷰)
- 카테고리 필터 탭 (전체 / 디자인 / 마케팅 / AI 도구 / ...)

### B-3. 정리가 필요한 링크 섹션
- 데드링크 N개 배너 (→ E-1)
- 분류 미완료 링크 N개 배너

## 5. 상태 정의

### 빈 상태 (Empty States)

| 화면 | 빈 상태 트리거 | 표시 내용 |
|------|------------|---------|
| B-1 (오늘의 영감) | 북마크 0개 또는 방치 링크 없음 | "아직 충분한 영감이 쌓이지 않았어요. 더 저장해보세요!" + 추가 유도 CTA |
| B-2 (새로 추가) | 최근 7일 내 저장 없음 | "이번 주 새 링크가 없어요" + 링크 추가 버튼 |
| C-3 (검색 결과 없음) | 검색어에 해당 링크 없음 | "'{검색어}'에 맞는 링크를 찾지 못했어요. 다른 키워드로 시도해보세요" |
| E-1 (데드링크 없음) | 스캔 결과 데드링크 0개 | "모든 링크가 살아있어요 ✓" |

### 로딩 상태 (Loading States)

| 상황 | 표시 방식 |
|------|---------|
| 임포트 중 | 프로그레스 바 + 카운터 ("392/840 가져오는 중") |
| AI 분류 중 | 스켈레톤 카드 + "분석 중..." 레이블 |
| 검색 실시간 | 인풋 옆 스피너 (300ms debounce) |
| 페이지 첫 로드 | 카드 그리드 스켈레톤 |
| 데드링크 스캔 중 | 정리 센터 배너에 프로그레스 표시 |

### 에러 상태 (Error States)

| 에러 | 화면 ID | 표시 내용 | 복구 액션 |
|------|--------|---------|---------|
| 임포트 실패 (파싱 오류) | A-3-ERR | "파일을 읽지 못했어요. 다른 형식으로 시도해보세요" | 다시 시도 / HTML 파일로 전환 |
| 임포트 부분 성공 | A-3-PARTIAL | "N개는 가져왔지만 M개를 읽지 못했어요" | 실패 목록 다운로드 |
| AI 분류 실패 | 카드에 배지 | "분류 실패" 배지 + 수동 지정 CTA | 카테고리 직접 선택 |
| 네트워크 오류 | 토스트 | "연결이 끊겼어요. 나중에 다시 시도해주세요" | 재시도 버튼 |
| OG 이미지 로드 실패 | 카드 썸네일 영역 | 파비콘 + 도메인명 폴백 이미지 | 자동 처리 (사용자 액션 불필요) |
| Chrome API 접근 거부 | A-2 | "브라우저 접근 권한이 필요해요" | HTML 업로드로 전환 안내 |
